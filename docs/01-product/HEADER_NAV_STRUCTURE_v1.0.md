# Header Nav Structure v1.0

## 目标
让站点顶部导航更清楚地区分“公开官网层”和“Portal 工具层”。

## 当前结构
### Brand Block
- `Culture Escrow`
- `Official Website + Portal`

### Public Navigation
- Home
- About
- Services
- Team
- Contact

### Portal Navigation
- Daily Tools

## 设计意义
1. 让用户一眼看出这是“官网 + Portal”的双层结构
2. 强化 `daily-tools` 不是普通公开页，而是 Portal 入口
3. 为后续继续扩展 Portal 导航项留出位置
